# EastWind Loan

A web-based loan marketplace designed to connect borrowers with lenders through a centralized loan application and management platform.

# Overview

EastWind Loan provides a platform where borrowers can explore loan products, submit applications, and manage their loan repayments. Lenders can publish loan products, review applications, and manage approved loans.

# Features

Loan Marketplace – Browse and explore available loan products from different lenders.
Loan Applications – Submit applications and track application progress.
Loan Management – Review applications, make loan offers, and manage loan disbursements.
Repayment Tracking – View repayment schedules and monitor payment status.
AI Integration – AI-assisted loan application analysis and information summarisation.
